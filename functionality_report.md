# Отчет по применению технологий из системы оценивания

## 1. Использование Redis для кэширования предварительно отранжированных списков анкет

**Описание:**
Redis используется для кэширования списков анкет, которые пользователь будет просматривать. Это позволяет ускорить выдачу анкет и снизить нагрузку на базу данных.

**Как применено:**
- **Файл:** `services/bot_gateway/app/redis_cache.py`
  - Функция `prefetch_profiles` запрашивает отранжированные анкеты из Profile Service и сохраняет их в Redis список (LPUSH/RPUSH) с ключом `user:{user_id}:recommendations`.
  - Функция `get_next_profile` получает следующую анкету из кэша (LPOP). Если в кэше остается мало анкет (<= 2), запускается процесс предзагрузки новых.
- **Файл:** `services/bot_gateway/app/main.py`
  - При старте просмотра анкет (`start_viewing`) вызывается `get_next_profile`, которая работает с Redis.
  - После взаимодействия с анкетой (лайк/дизлайк) также вызывается `get_next_profile` для получения следующей из кэша.
- **Файл:** `docker-compose.yml`
  - Сервис `redis` поднят как отдельный контейнер и доступен для `bot-gateway` и `profile-service`.

## 2. Использование S3 хранилища для изображений (Minio)

**Описание:**
Для хранения изображений используется MinIO - совместимое с S3 объектное хранилище. Это позволяет масштабировать хранение файлов и обеспечивает высокую доступность.

**Как применено:**
- **Файл:** `docker-compose.yml`
  - Добавлен сервис `minio` с образом `minio/minio:latest`.
  - Настроены переменные окружения для доступа (`MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD`).
  - Открыты порты `9000` (API) и `9001` (Console).
  - Настроен `volume` для сохранения данных (`miniodata`).
  - Сервисы `profile-service` и `bot-gateway` теперь зависят от `minio` и получают его адрес через переменные окружения (`MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET`).

- **Файл:** `services/profile_service/app/minio_client.py`
  - Реализован клиент для взаимодействия с MinIO.
  - Функция `ensure_bucket_exists` создает бакет для фотографий при старте.
  - Функция `upload_photo` загружает фотографии пользователей в MinIO.

- **Файл:** `services/profile_service/app/main.py`
  - Добавлен эндпоинт `POST /api/v1/profiles/{user_id}/photo` для загрузки фотографий.
  - Фотографии сохраняются в MinIO, а в базу данных записывается только путь к файлу.

- **Файл:** `services/bot_gateway/app/main.py`
  - При регистрации и редактировании профиля фотографии теперь загружаются в MinIO через Profile Service.
  - При показе анкет фотографии отображаются по ссылке из MinIO.

- **Файл:** `services/profile_service/requirements.txt` и `services/bot_gateway/requirements.txt`
  - Добавлена библиотека `minio==7.2.20`.
